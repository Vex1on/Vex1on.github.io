FIRTACH

Fully Intelligent Robot That Always Can Help

FIRTACH's original idea was to have it answer basic things with just text input. Now it's a voice assistant built into my VEX Workspace dashboard: it listens for a wake word, thinks with an AI model running locally on my PC, and can answer questions, work out equations, chat to you and control things like lights and other smart home devices.

Version 0.1 – 0.3

In the early days FIRTACH (Version 0.1) just didn't work. It was only a glitchy file that didn't work out because it was Python in a .batch file. It was also called "VEX Assistant" because I didn't know what to call it yet.

Version 0.4

In these versions FIRTACH kind of worked and could use basic functions like telling the time and date, using the user's text as the input.

Version 0.6 – 0.10

These versions use Discord's bot API to allow any user in a server with FIRTACH to ask it questions and get picked-out responses, using a machine learning response module called neural intents by NeuralNine. These versions also became the first ones that actually worked better than all the previous versions, which broke after one query.

Version 0.12

This version is the first one close to the original idea. It uses the user's voice as the input and a module called pyttsx3 for the voice output (text to speech).

Version 1.0

The latest version is built into my VEX Workspace dashboard. Say the wake word "F" and ask for something, or type it instead, and you can carry on talking for a few seconds after each reply without saying the wake word again. It runs a local AI model through Ollama that has tools to use rather than guessing, and it replies in a neural British voice.

It can now check the weather and BBC News, look things up on Wikipedia, do maths and convert units and currencies, set timers and reminders, keep a to-do list, play Apple Music, control media and volume, open apps and websites, control smart home devices, give a morning briefing and remember things about you. The dashboard's FIRTACH page also shows live cards for upcoming reminders, the to-do list and headlines.
