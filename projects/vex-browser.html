VEX Browser

Simple. Secure. Private.

Creating the VEX internet browser was pretty easy, but it also makes the browser snappy and more secure than others because it doesn't actually store any data that you browse: cookies, search history and so on. It doesn't have much yet, but soon I'm sure there will be more to it.

Uses Google by default

The URL bar doesn't actually search with a search engine, it only uses the full URL of a website to enter it. But you can set a default URL to start up on when you launch, so that you don't need to use Google, or you could have no start page and be completely invisible to search engine companies.

Function buttons

Because of its simplicity it only has 5 buttons on the whole UI: Back, Forward, Refresh, Google Search (takes you to google.com) and YouTube, which is just a hyperlink to YouTube.

Functionality

VEX Browser can stream video on any site as long as the website doesn't require a certain browser for its service. Apart from that it works just as well as Google Chrome or Microsoft Edge.
