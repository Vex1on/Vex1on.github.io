How do I get a token?
  1. Open GitHub's new token page.
  2. Under Repository access, choose Only select repositories and pick Vex1on.github.io.
  3. Under Permissions, set Contents to Read and write.
  4. Generate the token, then paste it above.

Your token is stored only in this browser and sent only to GitHub. Treat it like a password.
