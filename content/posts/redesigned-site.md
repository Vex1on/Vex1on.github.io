## Site Redesigned with AI
For the new and improved site, Claude code running the Opus 5.5 model was used and was fed the latest push of the old site.

## Prompt Used
“Redesign the Vexion site to include a user login system that allows me to add posts and make nice visual and animation improvements, also reorganise the file system so its more well organised.”

## The Result
Claude implemented fluid animations, clean design and a streamlined way for me to post to the website, allowing me to quickly add posts with a GitHub token login system. 

The post writing feature includes buttons to change the format of text and allows me to preview the post on the fly. 

Claude also considered something I didn’t initially plan on and that was optimising the site further for mobile. This was something that was done to an acceptable standard on the old site but Claude fully changed the sites view on mobile to account for its different aspect ratios to fully take advantage of the different available space.

All this was done while keeping the old style of the site with its colour scheme and imagery, while sprucing up everything around that.
